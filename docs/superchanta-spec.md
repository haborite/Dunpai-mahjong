# スーパーチャンタ麻雀（超帯么九麻雀 / Super Chanta）仕様

4人打ちの立直麻雀（じゃんたまルールがベース）に、盾牌とオープン立直を加えたもの。URL は `/superchanta/`、内部IDは `superchanta`。

## 合意済みのルール

- 基本は日本の立直麻雀（じゃんたま準拠）。符計算、満貫〜数え役満、本場（1本300点）、供託（立直1,000点）、ノーテン罰符3,000点は通常どおり。
- 食い替えあり（鳴いた直後に現物・筋も切れる）。
- 赤ドラは5ではなく、各色の3と7に1枚ずつ（計6枚）。牌画像 `Man3-Dora.svg` などは既存の `X3.svg` を赤ドラの配色に塗り替えて作った。
- 役と翻数の初期値（門前／副露。「—」は成立しない）

| 純全帯么九 | 6 / 5 |

| 二盃口（鳴きあり） | 6 / 5 |
| 三色同刻 | 6 |
| 混老頭 | 6 |

- 盾牌
  - 盾牌スペースは最初は空。最初に手牌から選ぶ手順はない。局をまたいだ持ち越しもない。
  - 一局に一度だけ、打牌を河ではなく自分の盾牌スペースに表向きで置ける（交換ではなく追加）。
  - 効果は盾麻雀と同じ：誰かがツモ和了したとき、自分の盾牌が和了者の待ち牌（和了牌だけでなく、和了前の手の待ち牌すべて）に含まれていれば、自分の支払い（本場分を含む）が0点になる。ロン・流し満貫には効かない。
  - オープン立直者のツモ和了には盾牌の効果が効かない。
- 点数とゲームの終了
  - 0点スタート。マイナスでも続行し、点数に関係なく立直できる。
  - 東1局から始め、東4局（4人目の親）以降は「その局の配牌時点で単独トップだった人が、その局で和了し、かつその局の収支がプラス」になった時点で終局。
  - 終わらなければ南入し、以降 西→北→東… と続く（終了の判定は同じ）。点数がマイナスになっても終わらない。
- 部屋の設定（ホストのみ・対局前のみ）
  - すべての役の翻数（門前・副露それぞれ。0 でその役なし。役満の行は役満の倍数）。「初期値に戻す」ボタンあり。
  - 盾牌スペースの枚数：0〜4（初期値 1）。N 枚なら一局に N 回まで盾牌スペースに置ける。
  - 持ち時間：裸雀と同じ（標準 3〜60 秒、予備 0〜120 秒、無制限）。
  - ホストが最後に使った設定はブラウザに保存される。

## 実装時に決めた細目（要確認）

| 項目 | 採用した仕様 | 理由・備考 |
|---|---|---|
| 盾牌スペースに置いた牌 | 河に出ないので、ポン・チー・カン・ロンの対象にならない | 「河ではなく盾牌スペースに捨てる」から。盾牌に置くのは安全な打牌にもなる |
| 盾牌とフリテン | 盾牌の牌は、置いた本人の捨て牌として扱う（フリテンの判定に含む） | 盾麻雀と同じ |
| 立直と盾牌 | 立直の宣言牌を盾牌スペースに置ける（宣言牌は鳴かれないのでそのまま立直成立）。立直後は置けない | 盾麻雀の「立直＋盾交換」に相当 |
| 盾牌と途中流局・流し満貫 | 盾牌に置いた牌は四風連打・流し満貫の判定に含めない（河の牌だけで判定） | 第1打を盾牌に置いた場合、その局の四風連打は成立しない |
| オープン立直の翻数 | 立直の代わりに1翻（オープン立直＋立直で2翻、ではない） | 盾麻雀と同じ扱い。設定で変更可 |
| ダブル立直をオープンで | 「ダブル立直（オープン）」としてダブル立直の翻数（2翻）。盾牌無効の効果あり | |
| オープン立直の公開 | 宣言した時点で手牌と待ちを全員に公開 | |
| 七対子の4枚使い | 同じ牌4枚を2対子として数える。シャンテン数・待ち・テンパイ判定も同様 | |
| 一盃口・二盃口・一色三順（鳴きあり） | チーした順子も含めて数える | |
| 一色三順と一盃口 | 複合しない（同じ順子4組なら二盃口との高い方） | 門前の同じ順子3組は三連刻＋三暗刻とも読めるので、高い方の読みが採用される |
| 三連刻 | 同じ色の連続した3つの数の刻子（槓子を含む） | |
| 十二落抬 | 暗槓以外の4副露で単騎待ち和了 | |
| 五門斉 | 萬・筒・索・風牌・三元牌をすべて含む（七対子でも成立） | |
| 大于五／小于五 | 字牌なしで、すべて6〜9／1〜4の数牌（七対子でも成立）。断么九などとは複合する | |
| 終局条件の「得点を得た」 | その局の収支（供託の受け取りを含む）がプラス | 盾牌で全員の支払いが0になり供託もなければ終わらない |
| 配牌時の単独トップがいない | その局では終わらない（同点トップや全員0点のとき） | |
| ダブロン・トリプルロン | ダブロンあり。三家和は途中流局 | じゃんたま準拠 |
| ダブロン時の本場・供託 | 本場は和了者それぞれが受け取る。供託は放銃者から見て近い人（上家取り） | |
| 途中流局 | 九種九牌・四風連打・四家立直・四開槓・三家和。いずれも親の連荘 | じゃんたま準拠 |
| 連荘 | 親の和了、または流局時に親がテンパイなら連荘（形式テンパイ可） | |
| 流し満貫 | 満貫ツモと同じ支払い（子 2,000/4,000、親 4,000オール）。盾牌は効かない。成立時はノーテン罰符なし | |
| 立直の条件 | 門前・山の残りが4枚以上。点数は問わない | 0点スタートでマイナスもあるため |
| 包（責任払い） | なし | 未実装 |
| 終局時の供託 | トップの得点に加算 | |
| 同点の順位 | 起家に近い順 | |
| 起家 | ランダム | |
| 槍槓・カンドラ・カン制限 | 裸雀と同じ（加槓は槍槓可、暗槓は国士無双のみ。暗槓は即めくり、明槓・加槓は打牌後。計4回まで） | |

## 画面

- 自分が下、下家が右、対面が上、上家が左。中央に4人の河と、局・残り枚数・ドラ・点数を表示。
- 各プレイヤーの横に盾牌スペース（空き枠は点線）。立直の宣言牌として置いた盾牌には「立」の印。
- オープン立直者の手牌は紫の枠で全員に公開され、待ち牌も表示される。
- 上部に「終了判定中：○○が和了して得点を得たら終局」を表示（東4局から）。配牌時トップの人には「配牌時トップ」のバッジ。
- 手番の操作：ツモ／立直／オープン立直／盾牌へ置く／暗槓／加槓／九種九牌。「盾牌へ置く」を押してから牌を選ぶと、その牌が盾牌スペースに置かれる（立直と組み合わせ可）。
- 結果画面に、盾牌で支払いを防いだ人（またはオープン立直で無効になった人）を表示。

## NPC

- 見えている情報（自分の手牌・河・副露・盾牌・ドラ表示牌・オープン立直の手牌）だけで判断する。
- 牌効率（シャンテン数と見えていない残り枚数で数えた有効牌）で打牌を選ぶ。
- 立直者がいるとき、2シャンテン以上ならベタオリ、それ以外は危険度を加味する。危険な牌を切るときは盾牌スペースを使う。
- 他家の盾牌に自分の待ち牌があるときはオープン立直を選ぶ。

- `src/games/superchanta/engine.js`: 対局エンジン（4人、各視点ごとの情報だけを返す `getView`）
- `src/games/superchanta/npc.js`: NPC
- `src/games/superchanta/room.js`: 4人用の部屋
- `src/riichi/shanten.js`: 七対子の4枚使いオプション（`{ chiitoiQuads: true }`）を追加。裸雀の動作は変えていない
- `public/superchanta/`: クライアント
- `test/superchanta.test.js`: テスト
